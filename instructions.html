Augment – How to Use the Application User Guide

Augment is an AI-augmented code editor and mini-IDE. It combines a file explorer, tabbed Monaco editor, and a local AI assistant powered by Ollama.

1. System Requirements

  • Node.js & npm installed.
  • Ollama installed and running locally.
  • A code project folder with source files (JavaScript, TypeScript, C#, Python, HTML, CSS, etc.).

2. First-Time Setup

2.1 Install dependencies

npm install
npm run icons

2.2 Start Ollama

Open a terminal and run:

ollama pull llama3.2
ollama serve

You can use any local model you like; just make sure the name matches the Model field in the AI panel inside Augment.

2.3 Start Augment

npm start

This launches the Electron app with the Augment interface.

3. Understanding the Interface

3.1 Top Bar

  • Open File – Open a single file into a new tab.
  • Open Folder – Select a folder and populate the left explorer tree.
  • Save / Save As – Save the currently active tab’s file.
  • New File – Create a new untitled tab in the editor.
  • Language Dropdown – Override the syntax highlighting language for the current tab (or let it stay on Auto Detect to match file extension).
  • Help → Documentation / Instructions (in the app menu) – Opens the documentation and this guide in your default web browser.

3.2 Left Sidebar – File Explorer

  • Shows the folder you opened with Open Folder.
  • Directories are expandable/collapsible.
  • Files open into tabs when you click them.
  • Clicking a folder will:
    • Select that folder as the target for new folders.
    • Toggle its collapsed/expanded state.

3.3 Center – Tabs & Monaco Editor

  • Each open file appears as a tab in the tab bar.
  • An orange dot (●) in the tab indicates unsaved changes (dirty state).
  • The main editor uses Monaco (similar to VS Code) with:
    • Syntax highlighting
    • Line numbers
    • Minimap (small preview) on the right
    • Mouse selection and standard keyboard shortcuts (copy/paste, undo/redo, etc.)

3.4 Right Panel – AI Assistant

  • Model input – Name of the Ollama model to use (e.g. llama3.2).
  • Scrollable message history showing user prompts and AI responses.
  • Buttons:
    • Ask AI – Ask a general programming question.
    • Ask About Current File – Ask AI to analyze the full content of the active editor tab.
    • Explain Selection – Explain the currently highlighted code.
    • Refactor Selection – Suggest a cleaner / more maintainable version of the selected code.
    • Generate Tests – Generate unit test ideas/code for the selected function or block.

4. Working With Files and Folders

4.1 Opening a Folder

  1. Click Open Folder in the top bar.
  2. Select the root directory of your project.
  3. The left sidebar will populate with a folder tree.

4.2 Opening Files

  1. In the sidebar, click a file.
  2. A new tab appears in the center, and the file is loaded into Monaco.
  3. Click other files to open more tabs.

4.3 Creating New Files

  1. Click New File in the top bar.
  2. An untitled tab is created (e.g. Untitled-1).
  3. Type your code, then click Save or Save As to write it to disk.

4.4 Saving Changes

  • Save – Saves to the existing file path (if the tab already has one).
  • Save As – Prompts for a location and file name, then saves the content.
  • The dirty indicator (●) clears once the file is successfully saved.

4.5 Creating New Folders

  1. Open a folder via Open Folder.
  2. In the sidebar, click the folder where you want the new folder to be created (it becomes the selected directory).
  3. Use the New Folder control in the sidebar (if you’ve added that feature) to input a folder name.
  4. The folder is created on disk and the tree refreshes.

5. Using the AI Assistant

5.1 Basic Chat

  1. Ensure Ollama is running.
  2. Check the Model field in the AI panel (e.g. llama3.2).
  3. Type your question in the AI text area.
  4. Click Ask AI.
  5. The request is sent to Ollama, and the response appears in the AI panel.

5.2 Ask About the Current File

  1. Open a file in the editor.
  2. Optionally, describe what you want (e.g. “Review this file for obvious bugs and improvements”).
  3. Click Ask About Current File.
  4. Augment sends both your question and the full file content to the model for context-aware analysis.

5.3 Explain / Refactor / Generate Tests (Selection-based Tools)

  1. Select the relevant code in the Monaco editor (function, class, or block).
  2. Click:
    • Explain Selection – to get a human-readable explanation.
    • Refactor Selection – to receive a suggested improvement.
    • Generate Tests – to get sample unit test code or scenarios.
  3. Results are shown in the AI panel. You can manually copy/paste suggested code back into the editor.

5.4 Changing the Model

  • If you have multiple models in Ollama (e.g. llama3.2, codellama, etc.), type the desired model name into the Model input.
  • All subsequent AI requests use that model.

5.5 Error Handling

  • If the AI panel shows an error:
    • Verify that Ollama is running (ollama serve still active).
    • Ensure the model name is correct and the model is pulled.
    • Check the console in the terminal where you ran npm start for details.

6. Building Augment (Optional)

If you have electron-builder configured, you can create distributable builds:

npm run build

This typically generates platform-specific installers or app bundles in a dist/ directory.

7. Tips & Best Practices

  • Use AI for guidance and suggestions, but always review generated code and tests.
  • Keep your Ollama models updated for best quality and performance.
  • Consider separate project folders for different languages/frameworks to keep the explorer organized.
