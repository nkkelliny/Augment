Augment AI-Augmented IDE

Augment is a minimal IDE with a built-in AI assistant powered by your local Ollama models.

Features

  • Monaco editor with syntax highlighting
  • File explorer and multi-tab editing
  • Local AI assistant (Ollama) for:
    • General code questions
    • “Ask about current file”
    • Explain / refactor selected code
    • Generate tests for selected code

Requirements

  • Node.js & npm
  • Electron (installed via npm install)
  • Ollama running locally on http://localhost:11434

Running Augment

npm install
npm run icons
npm start

Basic Workflow

  1. Open a folder using the Open Folder button.
  2. Click files in the explorer to open them in tabs.
  3. Use the language dropdown to adjust syntax highlighting if needed.
  4. Use the AI panel on the right to:
    • Ask general questions (Ask AI).
    • Ask about the current file (Ask About Current File).
    • Explain or refactor selected code, or generate tests.

Ollama Model

The model name can be changed in the AI panel (default is llama3.2). Make sure the model is pulled in Ollama: 

ollama pull llama3.2
ollama serve

Troubleshooting

  • If AI calls fail, ensure Ollama is running and the model exists.
  • Check the console output where you started npm start.
